# Contributing

Contributions to the research prototype are welcome subject to the maintainer's review.

1. Open an issue describing the proposed change or bug and specify Alice/Bob role, Pi OS, and the relevant module.
2. Create a focused branch; avoid unrelated changes to the protocol and the GUI.
3. Check Python syntax with `python -m compileall -q .` and test with the actual hardware where available.
4. Include reproducible steps, expected behavior, and sanitized logs. Never include secret keys or SCP03 credentials.
5. Clearly distinguish measured hardware results from simulations or GUI-only behavior.

Hardware access and credentials are not provided by this repository.
